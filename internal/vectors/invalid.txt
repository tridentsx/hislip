# HiSLIP malformed header vectors
#
# Inputs a conforming decoder must reject, with the reason it must reject them.
#
# Format, whitespace separated, one record per line:
#
#   name  wire-hex  reason
#
# wire-hex  the bytes as hex, or "-" for an empty byte string
# reason    "prologue"  the two-byte "HS" signature is absent
#           "short"     fewer than 16 bytes were supplied
#
# A decoder must not reject anything else at this layer. Undefined message
# types, reserved message types and implausible payload lengths all decode
# successfully on purpose, because a receiver has to decode a header it intends
# to reject in order to consume the payload and stay synchronised with the peer.
# Those cases live in headers.txt, not here.
